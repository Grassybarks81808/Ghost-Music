## Downloads

| Build | File | Size | Requirements |
| --- | --- | --- | --- |
| **Windows** (installer) | `GhostMusic-1.0.0-x64.exe` | ≈169 MB | Windows 10/11 x64. Per-user install, desktop + Start-menu shortcuts, uninstaller. No admin rights. |
| **Windows** (portable) | `GhostMusic-1.0.0-portable.exe` | ≈169 MB | Windows 10/11 x64. Single file, no install. First launch unpacks to a temp folder. |
| **Android** | `GhostMusic-1.0.0.apk` | 35 KB | Android 8.0+ (minSdk 26). Needs a reachable Ghost Music server. |
| Checksums | `SHA256SUMS.txt` | | Verify with `sha256sum -c SHA256SUMS.txt`. |

> **Windows:** the installers are not code-signed, so SmartScreen shows *"Windows protected your PC"*. Choose **More info → Run anyway**. Signing with your own certificate removes the warning (`CSC_LINK` / `CSC_KEY_PASSWORD`).

> **Android:** the APK is a client. Start the Windows app, open **Ghost Music → Connect a phone on this network**, then enter the address it shows. Both devices must be on the same Wi-Fi, and phone mode has no authentication — use it only on a network you trust.

## What is in this release

**Windows desktop app.** The installer is not a wrapped website: it starts the bundled Next.js server as a child process on a free loopback port, waits for `/api/health`, then loads it in a sandboxed window. Service workers, HTTP range requests, native downloads, and the Web Audio analyser all behave exactly as they do on the web, and no server has to be installed on the machine. The NSIS installer and the portable build both contain the server, FFmpeg, yt-dlp, the artwork, and the eight Ghost Sessions MP3s — nothing is downloaded at first run.

**Android app.** A thin native shell around the same client, with a first-run server prompt verified against `/api/health`, offline playback through the service worker cache, and a `GhostMusic.saveFile` bridge that streams finished MP3s to `Music/Ghost Music` in 384 KB chunks because a WebView cannot follow a `blob:` download. Signed with a v2 signature; launcher icons for all five densities.

**Embedded PostgreSQL.** Packaged builds no longer need a database server: with no `DATABASE_URL` the app runs on PGlite — PostgreSQL compiled to WebAssembly — using the identical Drizzle schema and queries. A `DATABASE_URL` still takes priority, so the server deployment is unchanged.

**Original media.** All six covers, the hero image, every app icon (PWA, Windows `.ico`, Android mipmaps), and the eight Ghost Sessions instrumentals are generated by scripts in this repository, and the 28 MB of MP3s is committed so a clone builds and runs without regenerating anything.

**Not verified, stated plainly:** installing the APK on a physical device or emulator, code signing, and the PostgreSQL branch end to end — none of those were possible on the build machine. `npm run lint` reports four pre-existing warnings unrelated to these builds; the type and build gates are clean.

## Notes

- Download only music you own or are authorised to save. YouTube extraction requires an explicit permission confirmation in the app, and the bundled Ghost Sessions originals are free to use.
- Libraries are scoped to a random browser identity, not authenticated accounts. Add real authentication before treating them as private.
- Extraction is capped at 30 minutes and 100 MB per track, with per-listener concurrency limits.
